# 爆片分析

团队内部使用的 TikTok 带货视频多模态拆解工具。支持 TikTok 链接和本地视频，输出中文分析并按产品长期归档。

## 已实现

- 产品档案：图片、品类、市场、售价、卖点、目标用户、痛点、竞品、合规词和备注
- 分析页面可快速新增产品，只需名称、类目和选填 PID，创建后自动选中
- 最多 10 条 TikTok 链接或本地视频批量排队
- 队列任务可随时停止，正在进行的模型请求会被中断且不会自动恢复
- 英语、西语原文识别及中文翻译
- 自动分镜和逐镜头画面/声音分析
- 清晰度、美感、光线、产品主体、流量、转化、声音和节奏评分
- 钩子、爆点、卖点、信任点、CTA 标记
- 爆点截图与 3–10 秒关键片段
- AI 仿写口播和复拍分镜
- 两条视频对比
- 按产品、账号、日期和文案搜索
- 团队人工标记“优质 / 普通 / 较差”，用于同产品后续分析参考
- 长期学习系统：每条完整报告会沉淀为视频经验，按产品、品类和全局三层整合
- 新视频自动检索相似历史案例；人工标签和备注拥有最高学习权重
- 学习中心可查看已学习数量、可信度、有效钩子、胜出结构和常见风险
- 原视频、封面、截图、片段和报告长期保存在本机
- 已完成、失败或已停止的视频可二次确认后永久删除，并同步清理全部本地媒体
- 飞书双向机器人：单聊直接发送，群聊必须 @机器人，支持自然表达的“产品名称 + 选填 PID + 最多 10 条 TikTok 链接”
- 飞书机器人实时更新排队、下载、识别、分镜、分析和报告生成进度；重复链接优先返回历史报告
- 完成后返回含六维评分的飞书卡片和完整飞书文档，文档包含原文案、中文翻译、逐镜头分析、截图和爆点片段
- 卡片可直接标记优质/普通/较差或重新分析，并同步进入本地长期学习系统
- 网页中的已完成报告可选择最近使用的人或群聊，一键发送到飞书

## 第一次使用

1. 双击项目里的 `启动爆片分析.command`。
2. 浏览器打开后进入“设置”。
3. 在对应平台撤销之前发到聊天里的旧密钥，生成新密钥后在设置页录入。
4. 分别点击“测试连接”。Qwen 的接口地址必须和密钥所在地域一致。
5. 建立产品档案，然后提交视频。

## 飞书机器人设置

1. 在飞书开放平台创建企业自建应用并启用机器人。
2. 在事件订阅中选择“使用长连接接收事件”，添加接收消息事件。
3. 添加卡片交互回传，让报告卡片上的标签和重新分析按钮生效。
4. 按网页设置页的清单开通消息、群信息、用户基本信息、文档、云空间、素材和协作者权限。
5. 发布应用，把机器人加入需要使用的群聊。
6. 回到本工具设置页填写 App ID 和 App Secret，启用后点击测试连接。

## 飞书多维表格自动化

云端接口：`/api/feishu/automation`。在飞书自动化中使用“发送 HTTP 请求”，方法选择 `POST`，请求体至少传入：

```json
{
  "appToken": "多维表格 App Token",
  "tableId": "数据表 ID",
  "recordId": "触发记录 ID",
  "secret": "自动化接口密钥",
  "fields": {
    "产品链接": "https://www.tiktok.com/shop/pdp/.../1732507663809155965",
    "产品名称": "产品中文名",
    "视频链接": "https://www.tiktok.com/..."
  }
}
```

「产品链接」应使用飞书的超链接字段并填写完整 TikTok Shop PDP 链接；商品 PID 由链接重新提取，不作为自动化触发条件。产品名称始终使用表格里人工填写的中文名。即使链接无效、缺少 PID 或商品资料解析失败，应用也会先按 Base 记录创建或复用唯一产品手卡、回写「产品手卡」，再把失败原因写入「手卡状态」。链接修正后再次点击会继续更新同一份手卡。

每次点击都会重新验证原始产品链接及路径 PID，不使用旧缓存跳过。解析器按单条事实验证：只要取得至少一条同 PID 官方商品页可以直接证明的资料，就把该条写入同一份手卡，并把状态标为「部分完成」；同一 PID、同一验证版本中这次未能再次证明的旧可信事实会保留，0 条可信事实时不修改已有可信资料。仅更新手卡中精确行首标签对应的系统基础信息：商品名称、产品链接、商品ID、SKU、产品主要功能、产品参数、使用方法、适用人群、使用场景；产品卖点、A–E、道具、人工段落、样片和历史分析保持不变。不使用相似商品、配件属性、产品名称、搜索摘要或模型常识补齐。Base 只回写现有的「商品ID」「产品手卡」「手卡状态」；不会把产品链接作为普通文本写回超链接字段。

应用还会自动处理视频分析和中文翻译，并回写「分析状态」「视频分析」「中文翻译」。字段名一致的其他多维表格可以直接复用；如字段名不同，可在请求体中增加 `fieldMap` 映射。

「排品表」历史产品可在每行增加按钮自动化：按钮把当前行的原始产品链接、产品名称和记录 ID 发送到同一接口。接口先生成或复用产品手卡并回写链接，再分析商品资料；不会在排品表新增记录。表格中的首个阶段状态是「手卡已就绪，资料刷新中」，随后变为「已完成」「部分完成：已写入 N 条可信资料」，或「手卡已就绪，资料刷新失败：原因」。

生产环境必须设置 `FEISHU_AUTOMATION_WEBHOOK_SECRET`，不要把接口裸露给公网。

生产环境还必须设置 `APP_BASIC_AUTH_USER` 和 `APP_BASIC_AUTH_PASSWORD`，用于保护网页后台及业务 API。飞书自动化接口继续使用独立的 Webhook Secret；健康检查仅访问 `/api/health`。

App Secret 只会在本机加密保存，不会显示在设置接口或写进源码。本机关闭时，第一阶段的飞书机器人会暂停接收消息。

## 数据位置

- 结构化数据：`.data/viral-video-analyzer.sqlite`
- 原视频及衍生文件：`.data/media/`
- 本机加密主密钥：`.data/secret.key`

整个 `.data` 文件夹需要一起备份；丢失 `secret.key` 后无法解密已保存的 API Key。
