# 补录手卡余额不足恢复

2026-09-23 线上商品取数返回 HTTP 402 / `INSUFFICIENT_CREDITS`。
原防重复收费逻辑把拒绝请求永久锁为失败，充值后手动补录也无法恢复。

现在仅对 HTTP 402 且错误码为 `INSUFFICIENT_CREDITS` 或官方文档的
`INSUFFICIENT_BALANCE` 开放下次手动点击重试。先校验原始响应摘要、PID、
国家和数据库状态，再用原更新时间原子领取重试资格；原失败证据整体归档，
不删除历史文件。成功商品、AI 失败、未知 402、网络超时和损坏缓存不解除保护。
单次点击没有余额重试循环，不新增扫描或后台自动重试，不修改飞书自动化配置。

充值后回到原行点击“补录手卡”即可；已创建的手卡按原 PID 规则复用，
后续成功资料仍只收费获取一次。无需清空手卡链接或删除数据库记录。

供应商规则：<https://openapi-doc.chuhaijiang.com/billing> 明确说明余额不足时
不会调用后端服务、不产生费用。实际余额充值必须由账户负责人完成。

验证覆盖：历史 402 在进程重启后恢复、有名/无名两种路径、并发按钮、
拒绝证据完整归档、余额仍不足时只尝试一次、重试发生超时后保持锁定、
未知错误和篡改缓存保持锁定，以及真实隔离 MySQL 的原子领取。
