## 归档范围

- `openai-product-analyzer.test.mjs`：旧 OpenAI 商品证据分析器。
- `product-parser-evidence.test.mjs`：旧商品页抓取、解析和搜索后备。
- `product-parser-contract.test.mjs`：从 `app.test.mjs` 分出的 43 条历史解析器源码断言；现用飞书、PID 和文档断言仍留在原文件。

前两个文件只调整了读取源码的相对路径，已与归档前版本核对一致。没有删除失败断言、增加 `skip` 或改为期望成功。
